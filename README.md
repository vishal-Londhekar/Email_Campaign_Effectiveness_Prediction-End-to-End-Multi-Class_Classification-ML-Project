# Email Campaign Effectiveness Prediction

> **Data Analyst & Business Intelligence Analyst portfolio project**

A Python machine-learning notebook for analysing email-campaign outcomes and building a multi-class classification workflow.

## Project objective

The project explores which campaign, audience, and engagement features are associated with different email outcomes. It demonstrates data preparation, class-imbalance handling, model comparison, and interpretation of classification results.

## Workflow

- Data inspection and quality checks
- Exploratory analysis of campaign outcomes
- Feature preparation and preprocessing
- Multi-class model training and comparison
- Evaluation with class-aware metrics
- Feature-importance and explainability analysis

## Dataset

**data_email_campaign.csv** contains 68,353 rows and 12 columns according to the project documentation. Confirm the dataset source, licence, and target definition before external reuse.

## Files

- **Email_Campaign_Effectiveness_Prediction_End_to_End_Machine_Learning_Capstone_Project.ipynb** — analysis notebook
- **data_email_campaign.csv** — dataset
- **README.md** — project documentation

## Tools

Python, pandas, NumPy, Matplotlib, Seaborn, SciPy, scikit-learn, imbalanced-learn, XGBoost, statsmodels, and SHAP.

## How to run

1. Install Python and Jupyter Notebook.
2. Install the packages used by the notebook, including pandas, NumPy, scikit-learn, imbalanced-learn, XGBoost, SHAP, statsmodels, Matplotlib, and Seaborn.
3. Keep **data_email_campaign.csv** in the repository directory.
4. Open **Email_Campaign_Effectiveness_Prediction_End_to_End_Machine_Learning_Capstone_Project.ipynb**.
5. Run the cells in order and review the class distribution before interpreting accuracy.

## Evaluation

Prioritise macro F1, class-wise precision and recall, the confusion matrix, and a clearly documented validation strategy. Do not describe the notebook as a production system unless a reusable training/inference pipeline and deployment artefacts are added.
